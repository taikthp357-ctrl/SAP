## If anything fails

**Layout not built:**
- Check VBA macro security (Trust Center → Enable all macros)
- Verify modules imported: Alt+F11 → Project Explorer → look for modCF_InputLayout, modCF_ControlButtons

**Buttons don't work:**
- Check OnAction property: Right-click button → Assign Macro → verify correct handler
- Check button names: btnCF_LoadWH, btnCF_CheckExecute, btnCF_Reset

**Worklist not refreshing:**
- Manually call `CF_RefreshInputWorklist` from Immediate Window
- Check DATA_CORE has data at row 5+
- Check constants: `WL_FIRST_DATA_ROW=9`, `WL_START_COL=5`, `WL_END_COL=14`

**Vietnamese messages missing:**
- CP12 reuses `modCF_VietnameseMessages` module (should be in vba_v28_ui staging)
- If not present, Result col shows English enums (acceptable fallback)

**Named Range missing:**
- Run `CF_ApplyInputLayout` again (it defines the Named Range)
- Or manually: Formulas → Name Manager → New → Name=CF_UI_STATUS_CELL, RefersTo=$A$42:$N$42

**Technical sheets visible:**
- They were VeryHidden by script — to re-hide: Alt+F11 → Immediate Window:
  ```vba
  ThisWorkbook.Worksheets("DATA_CORE").Visible = xlSheetVeryHidden
  ```
