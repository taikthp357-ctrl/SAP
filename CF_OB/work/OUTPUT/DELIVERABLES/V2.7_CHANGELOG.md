## Summary

V2.7 fixes the net-zero group allocation bug, closes the FAST-path CHECK/EXECUTE
lock hole, hardens the Single-MON-Broker invariant, and adds the LÀM MỚI reset
entry point — without rebuilding the workbook or writing to SAP offline.

## Added

- **`modCFGroupAllocator`** (new module, 9 public `CFAlloc_*` functions):
  - `CFAlloc_ComputeRequiredCreate` — `RequiredCreateQty = max(TargetQty − EffectiveQtyAfterPlannedCancelReplace, 0)`; EffectiveQty per ExecMode (CANCEL_PRDO_ZERO→0, REPLACE_CANCEL_CREATE→0, KEEP_EXISTING_CREATE_DELTA→SysQty).
  - `CFAlloc_IsContractAPass` — PRDO aggregate: `Abs(groupLiveQty − groupTarget) ≤ EPS`.
  - `CFAlloc_IsContractBPass` — member allocation: `RequiredCreateQty ≤ EPS`.
  - `CFAlloc_IsGroupComplete` — group complete only when **A AND B**.
  - `CFAlloc_PRDOAggregateWriteRequired`, `CFAlloc_AllocationWriteRequired`, `CFAlloc_MemberStatusText`, `CFAlloc_GroupStatusText`, `CFAlloc_SelfTest`.
  - `CFALLOC_EPS = 0.000001`; fail-safe error handlers default to write-required (never silently skip a needed Create).
- **`modCFResetUI`** (new module — the LÀM MỚI button #4):
  - `CF_ResetUI` / `CF_ResetUICore` — invalidates the plan lock (`PLAN!AJ2 = "RECHECK_REQUIRED_AFTER_RESET"`), clears the transient status cell, preserves RUN_HISTORY/RUN_LOG, `SAP_WRITE=0`.
  - `CFResetUI_SelfTest` — PASS (restores original lock cell after test).

## Changed

- **FAST executor `CWR_RunFastToCFCore`** (`modCodexWTRework`): now calls the existing `CWR_AssertQueuePlanLock` **before** `CWR_CreateOutboundWTFromExactCandidateFast` (lock@1300 < create@1318). Closes Seam 2 (FAST path previously wrote SAP without verifying CHECK's lock). `ASSERTQUEUEPLANLOCK_CALLS` = 7.
- **Group scheduler** (`CWR_SchedulerVerifyPRDOGroup` / `CWR_SchedulerVerifyQtySources`): `QtyReady` now gated by `CFAlloc_IsContractBPass`; success token `PRDO_QTY_ALREADY_TARGET|NO_QTY_WRITE` → `MEMBER_ALLOCATION_COMPLETE|REQUIRED_CREATE=0` / `CONTRACT_B_PASS`; added `QTY_GROUP_ALLOCATION_STATUS` log line. `CWR_ExecuteQtyGroups` integrates `CFAlloc_GroupStatusText`.

## Hardened (fail-closed)
