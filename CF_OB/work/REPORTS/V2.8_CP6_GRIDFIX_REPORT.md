## Changes

### 1. modCodexSAPReadOnly.bas — Grid lazy-load fix (Issue #6/#2)

**Root cause:** SAP GUI grids lazy-load off-screen rows. `GetCellValue(r, col)` on unrendered rows returns blank. Weak machine + many-row OB → bottom rows not rendered when tool reads → incomplete map → bỏ sót mã.

**Fix:** Added `Codex_EnsureGridRendered(grid, ses)` helper (after `Option Explicit`). Scrolls to last row, waits 500ms via `CWR_WaitIdle`, scrolls back to top — forces full render before any loop reads.

**Session variable:** resolved per-site by backward scan for `Set <gridVar> = <sesVar>.FindById` (correct for both `mon`-session and `ses`-session contexts).

Maps `Result` enum + `Detail` context → user-friendly Vietnamese strings for Phase 1b worklist.

**`CF_VN_GetMessage(result, detail)`** — covers: PASS, BLOCKED_SOURCE_PLAN_INCOMPLETE (Multi-batch / PICK_BIN_CANDIDATE_COUNT / generic), BLOCKED_QTY_GROUP_BASELINE, BLOCKED_INCOMPLETE_EXECUTION, BLOCKED_CREATE_OPEN, STOP (SOURCE_PLAN_INCOMPLETE / REGRESSION_GATE / generic), READY_FOR_CF, DONE_BY_USER_CF, DONE, PLAN_NEEDS_TAI_POSTING, Case Else.
