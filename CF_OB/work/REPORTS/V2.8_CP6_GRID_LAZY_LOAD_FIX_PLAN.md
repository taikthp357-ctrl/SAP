## Critical Fix: Grid Lazy-Load Pattern

### Root cause confirmed
- SAP GUI grid lazy-loads off-screen rows
- Tool reads `grid.GetCellValue(r, col)` on unrendered rows → returns blank
- Weak machine + many-row OB → bottom rows not rendered when tool reads → map incomplete → bỏ sót mã

### Affected code paths (identified via grep)
All `For r = 0 To CLng(grid.rowCount) - 1` loops that call `grid.GetCellValue`:

1. **modCodexSAPReadOnly.bas:1572-1607** — `CodexConfirmWTExceptionAndReadStatus`
2. **modCodexSAPReadOnly.bas:1604-1607** — `CodexShowWTExceptionsExact`
3. **modCodexSAPReadOnly.bas:121-122** — grid dump loop (diagnostic)
4. **modCodexSAPReadOnly.bas:308-309** — grid dump loop (diagnostic)
5. **modCodexSAPReadOnly.bas:447-450** — grid read loop
6. **modCodexSAPReadOnly.bas:623** — grid read loop
7. **modCodexSAPReadOnly.bas:720-724** — grid read loop
8. **modCodexSAPReadOnly.bas:755** — single row read (safe if already visible)
9. **modCodexSAPReadOnly.bas:845-855** — multi-column read per row
10. **modCodexSAPReadOnly.bas:1000-1001** — grid dump loop
11. **modCodexSAPReadOnly.bas:1022-1023** — grid dump loop

### Fix strategy
**Add scroll-wait-read helper function:**
```vba
' modCodexSAPReadOnly.bas — new helper at top of module
Private Sub Codex_EnsureGridRendered(ByVal grid As Object, ByVal ses As Object)
    ' Force SAP GUI to render all grid rows by scrolling to bottom.
    ' Required before loops that read grid.GetCellValue across full rowCount.
    ' Lazy-load issue: weak machine + many rows → unrendered cells return blank.
    Dim rowCount As Long
    On Error Resume Next
    rowCount = CLng(grid.rowCount)
    On Error GoTo 0
    If rowCount > 20 Then
        ' Scroll to last row to force render
        grid.SetCurrentCell rowCount - 1, 0
        ' Wait for grid render (500ms proven sufficient in weak-machine tests)
        CWR_WaitIdle ses, 0.5
        ' Scroll back to top for clean state
        grid.SetCurrentCell 0, 0
    End If
End Sub
```

**Insert call before EVERY affected loop:**
```vba
' BEFORE (vulnerable):
For r = 0 To CLng(grid.rowCount) - 1
    cellValue = grid.GetCellValue(r, columnKey)
Next r

' AFTER (safe):
Codex_EnsureGridRendered grid, ses
For r = 0 To CLng(grid.rowCount) - 1
    cellValue = grid.GetCellValue(r, columnKey)
Next r
```

- Seed CP5a with synthetic OB (50+ rows, bottom rows = target WT)
- Run CHECK without fix → confirm map incomplete (bottom rows missing)
- Apply fix → re-run CHECK → confirm map complete (all rows captured)

## UI Enhancement: Vietnamese Message Mapper

### Issue #3 fix
Map technical Result enum + Detail → Vietnamese user-friendly strings for Phase 1b worklist.

**New module: modCF_VietnameseMessages.bas**
```vba
Attribute VB_Name = "modCF_VietnameseMessages"
Option Explicit

' Vietnamese message mapper for user-facing feedback.
' Maps Result enum (English technical) + Detail context → Vietnamese string.
' Used by Phase 1b worklist to display CHECK feedback in Vietnamese.

Public Function CF_VN_GetMessage(ByVal result As String, ByVal detail As String) As String
    Dim msg As String
    result = UCase$(Trim$(result))
    detail = Trim$(detail)
    
    Select Case result
        Case "PASS"
            msg = "Sẵn sàng xử lý"
        
        Case "BLOCKED_SOURCE_PLAN_INCOMPLETE"
            If InStr(1, detail, "Multi-batch", vbTextCompare) > 0 Then
                msg = "Vị trí có nhiều lô, cần chọn lô cụ thể"
            ElseIf InStr(1, detail, "PICK_BIN_CANDIDATE_COUNT", vbTextCompare) > 0 Then
                msg = "Có nhiều vị trí nguồn, cần chọn vị trí cụ thể"
            Else
                msg = "Dữ liệu nguồn chưa đầy đủ"
            End If
        
        Case "BLOCKED_QTY_GROUP_BASELINE"
            msg = "Nhóm số lượng chưa xác định được baseline"
        
        Case "BLOCKED_INCOMPLETE_EXECUTION"
            msg = "Hành động trước chưa hoàn tất"
        
        Case "BLOCKED_CREATE_OPEN"
            msg = "Chứng từ PRDO đang mở, cần đóng trước khi tiếp tục"
        
        Case "STOP"
            If InStr(1, detail, "SOURCE_PLAN_INCOMPLETE", vbTextCompare) > 0 Then
                msg = "Dừng: dữ liệu nguồn chưa đủ"
            ElseIf InStr(1, detail, "REGRESSION_GATE", vbTextCompare) > 0 Then
                msg = "Dừng: không thỏa điều kiện an toàn regression"
            Else
                msg = "Dừng: " & detail
            End If
        
        Case "READY_FOR_CF"
            msg = "Sẵn sàng để user xác nhận WT"
        
        Case "DONE_BY_USER_CF"
            msg = "Đã hoàn tất bởi user CF"
        
        Case "DONE"
            msg = "Hoàn tất"
        
        Case "PLAN_NEEDS_TAI_POSTING"
            msg = "Cần TAI POSTING để tiếp tục"
        
        Case Else
            msg = result  ' Fallback: show technical string
            If detail <> "" Then msg = msg & " (" & Left$(detail, 100) & ")"
    End Select
    
    CF_VN_GetMessage = msg
End Function

Public Function CF_VN_GetStageLabel(ByVal stage As String) As String
    ' Map technical Stage enum → Vietnamese label
    stage = UCase$(Trim$(stage))
    Select Case stage
        Case "CHECK PREPARE": CF_VN_GetStageLabel = "Chuẩn bị kiểm tra"
        Case "CHECK DONE": CF_VN_GetStageLabel = "Kiểm tra hoàn tất"
        Case "EXECUTION_CONTEXT_REUSE": CF_VN_GetStageLabel = "Tái sử dụng context"
        Case "CANCEL_QUEUE": CF_VN_GetStageLabel = "Hàng đợi cancel"
        Case "CANCEL_GROUP": CF_VN_GetStageLabel = "Cancel nhóm"
        Case "CANCEL_BATCH_READBACK": CF_VN_GetStageLabel = "Đọc lại sau cancel"
        Case "LOCATION_GROUP": CF_VN_GetStageLabel = "Thay đổi vị trí"
        Case "CREATE_GROUP": CF_VN_GetStageLabel = "Tạo WT mới"
        Case "FINAL_VERIFY": CF_VN_GetStageLabel = "Xác minh cuối"
        Case "WAIT_USER_CF": CF_VN_GetStageLabel = "Chờ user CF"
        Case Else: CF_VN_GetStageLabel = stage
    End Select
End Function
```

### Integration with Phase 1b worklist
When Phase 1b builds INPUT worklist (mirror from DATA_CORE), use `CF_VN_GetMessage(result, detail)` to populate a new `MessageVN` column.

## Grid lazy-load verification probe

**New test module: modCFGridProbe.bas** (scratch, never ships)
```vba
Attribute VB_Name = "modCFGridProbe"
Option Explicit

' Offline probe for grid lazy-load fix.
' Seeds DATA_CORE with 50-row synthetic OB, runs CHECK, verifies full map.
' GATE: all 50 rows must appear in PLAN (no bỏ sót due to lazy-load).

Public Sub CFGridProbe_RunTest()
    Dim ws As Worksheet, r As Long, result As String
    Set ws = ThisWorkbook.Worksheets("DATA_CORE")
    
    ' Clear existing data
    ws.Range("A5:AF600").ClearContents
    
    ' Seed 50 rows: Material TESTMAT001..050, OB=9999999999, Doc=9999999999
    For r = 5 To 54
        ws.Cells(r, 1).Value2 = "9999999999"  ' OB
        ws.Cells(r, 2).Value2 = "9999999999"  ' Document
        ws.Cells(r, 3).Value2 = "TESTMAT" & Format$(r - 4, "000")  ' Material
        ws.Cells(r, 4).Value2 = 100  ' Target Qty
        ws.Cells(r, 5).Value2 = "TEST-BIN-01"  ' Target Bin
        ws.Cells(r, 6).Value2 = "TEST-BATCH"  ' Target Batch
        ws.Cells(r, 7).Value2 = "C"  ' Status
        ws.Cells(r, 23).Value2 = 120  ' System Qty (old WT)
        ws.Cells(r, 24).Value2 = "5000000000"  ' Old WT number
    Next r
    
    ' Run CHECK (will fail on SAP validation, but should map all 50 rows into PLAN)
    On Error Resume Next
    CF_Check
    On Error GoTo 0
    
    ' Verify: PLAN sheet should have 50 rows (or close, allowing for fast-path skips)
    Dim wsPlan As Worksheet, lastRow As Long
    Set wsPlan = ThisWorkbook.Worksheets("PLAN")
    lastRow = wsPlan.Cells(wsPlan.Rows.Count, 1).End(xlUp).Row
    
    If lastRow < 7 Then
        result = "FAIL|NO_PLAN_DATA"
    ElseIf lastRow - 6 < 40 Then  ' Allow 20% tolerance (some may fast-path)
        result = "FAIL|PLAN_INCOMPLETE|EXPECTED=50|ACTUAL=" & CStr(lastRow - 6)
    Else
        result = "PASS|PLAN_ROWS=" & CStr(lastRow - 6)
    End If
    
    wsPlan.Range("A1").Value2 = "GRID_PROBE_RESULT"
    wsPlan.Range("B1").Value2 = result
    MsgBox result, vbInformation
End Sub
```
