### STEP 1: Build the UI layout

1. Open `260821_CF_OB_V2.8_CP11_CF_CONTROL.xlsm` in Excel
2. Enable macros
3. Press **Alt+F11** to open VBA Editor
4. Press **Ctrl+G** to open Immediate Window
5. Type and run:

## If anything fails

**Layout not built:**
- Check VBA macro security (Trust Center → Enable all macros)
- Verify modules imported: Alt+F11 → Project Explorer → look for modCF_ControlLayout

**Buttons don't work:**
- Check OnAction property: Right-click button → Assign Macro → verify correct handler

**Data not refreshing:**
- Manually call `CF_RefreshControlTable` from Immediate Window
- Check DATA_CORE has data at row 5+

**Vietnamese messages missing:**
- CP11 reuses CP6 `modCF_VN_Messages` module
- If not present, Result col shows English enums (acceptable fallback)
