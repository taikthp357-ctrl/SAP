## Technical notes

**Merged cell conflict resolution:**
The INPUT sheet had pre-existing merged cells from V2.7 layout (old control panel at K:N rows 4-7, old status labels at E:J rows 5-10). These blocked worklist writes to E5:O504. Fix: `CF_ApplyWorklistHeaders` unmerges and clears E4:O10 before writing new headers, removing conflicts.

**Layout coordination:**
- OB entry area: A4:C10, A11:A506 (unchanged)
- Worklist: E4:O4 headers + E5:O504 data (new)
- Control panel: P4:S7 + buttons at P8/R8/P10/R10 (shifted from K:N)
- Status display cells (D6, F6, H6, D10, F10, H10 written by `RT_SetStatus`) remain functional — not affected by worklist

**Vietnamese rendering:**
All Vietnamese strings rendered at runtime via `ChrW()` (Unicode BSTR). VBA `.bas` files stored as CP1252 (ASCII-safe). Result enums (PASS, BLOCKED_*, STOP, etc.) mapped to user-friendly Vietnamese messages with context-aware detail (e.g. Multi-batch vs PICK_BIN_CANDIDATE_COUNT variants of BLOCKED_SOURCE_PLAN_INCOMPLETE).
